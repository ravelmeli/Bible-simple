## ➤ Description de la vidéo : 

« Alléluia » est-il seulement un cri de joie ? En hébreu, c'est un ordre : Halelou-Yah, « Louez Yah ! ». Découvrez en une minute d'où vient ce mot, ce qu'il veut dire et comment il est arrivé jusqu'à nous.

Halelou vient du verbe halal, « louer », à l'impératif pluriel : l'appel s'adresse à tout un groupe. Yah est une forme abrégée du nom de Dieu, YHWH. On trouve ce mot surtout dans les Psaumes, dont le dernier se termine par Halelou-Yah. Le grec l'a écrit sans le traduire, puis le latin, puis nos langues. Dans le Nouveau Testament, il n'apparaît que dans l'Apocalypse (chapitre 19). Ce n'est pas contre la joie : louer, c'est souvent chanter. Mais le mot lui-même est d'abord un appel à louer ensemble.
